# 화면 이미지 안내

[프로젝트 소개로 돌아가기](../../README.md)

2026년 10월 16일 실제 브라우저 화면을 촬영한 JPEG 이미지입니다. 화면을 따로 그린 목업이 아닙니다.

GitHub Pages에 배포하는 것과 동일한 정적 빌드를 로컬 브라우저에서 실행했습니다. 네 직무 전체 화면, 품질관리 검사 샘플, 품질보증의 SC-002 협력업체 샘플, 업무 영역과 상황별 처리 절차를 촬영했습니다. 회사·업체·검사 데이터는 가상이고, AI 문서는 데모에 포함된 기존 Claude 응답입니다.

이미지의 숫자와 날짜는 촬영 당시의 예시 상태입니다. README는 저장소 내부의 상대 경로로 이미지를 불러옵니다.
