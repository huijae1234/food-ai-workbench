# 네 직무 안내의 근거와 화면 설계

검토일: 2026-10-16

## 목적과 적용 범위

최초 버전은 특정 채용공고의 세 직무를 출발점으로 만들었다. 현재 버전은 공식 직무 소개와 직업 자료를 비교해 생산관리·생산기술·품질관리·품질보증을 별도로 설명한다. 식품 제조 맥락은 유지하지만 특정 회사의 조직도나 승인 권한을 모든 회사에 일반화하지 않는다.

이 문서는 공식 자료를 요약·비교한 프로젝트 설계 기록이다. 화면의 업무 주기, 협업 분담, 8개 처리 사례는 이해를 돕기 위해 재구성한 예시이며 표준작업절차, 법적 판단, 실제 회사 도입 성과가 아니다. 직무 범위와 최종 권한은 지원 회사·공장별로 확인해야 한다.

## 직무별 중심과 협업

| 직무 | 중심 | 혼동하지 않을 점 |
|---|---|---|
| 생산관리 | 계획·자원·납기를 조율하고 실적 차이를 확인 | 생산기술을 하위 직무로 두지 않음 |
| 생산기술 | 공정조건·작업방법·생산성을 개선하고 양산 준비 | 정비·수리를 단독 책임으로 표현하지 않음 |
| 품질관리(QC) | 검사·시험 신뢰성, 공정 품질, 부적합의 현장 근거 | 통계 경고를 자동 불합격이나 출하 승인으로 취급하지 않음 |
| 품질보증(QA) | 기준·문서·심사·변경·검증과 재발 방지 체계 | 클레임 회신만 하는 직무, 출하 이후에만 일하는 직무로 표현하지 않음 |

부적합·위생·법규는 QC·QA 공통으로 표시한다. 같은 도구를 두 직무에서 사용하되, 현장 증거와 시스템의 이행·효과 확인이라는 활용 관점을 구분한다. 고객 회신·업체 대응에는 고객상담·구매도 참여한다.

## 화면 구조와 넣은 이유

1. **주요 업무 영역:** 번호 없는 책임 범위. 영역을 선택하면 그 안의 업무만 나타나 긴 목록을 줄인다.
2. **상시·정기 업무:** 수행 시점과 협업 대상이 있는 순서 없는 목록. 매일 하는 일과 정기 점검을 함께 분류한다.
3. **상황 발생 시 업무:** 신제품, 변경, 부족, 부적합 등 사건에 따라 수행하는 별도 목록. 순서가 없다고 모두 상시 업무로 분류하지 않는다.
4. **상황별 처리 절차:** 시작 조건과 남길 결과가 있는 예시만 번호를 붙인다. 매일 모든 단계를 수행해야 한다는 오해를 줄인다.
5. **공통·협업 업무:** 무엇을 함께 하고 각 관점은 무엇인지 표시한다. 정비, 안전, 출하, 회수 등의 권한을 도구나 특정 직무에 임의 부여하지 않는다.
6. **연결 도구:** 기존 8종만 연결한다. 도구가 없는 업무는 설명임을 명시하며 계획 최적화·승인·문서관리 시스템 등을 새로 구현한 것처럼 표시하지 않는다.

## 도구 연결

| 기능 | 진입 직무 |
|---|---|
| 생산지표 분석·보고서 | 생산관리·생산기술 |
| 설비 이상 진단 | 생산기술 — 설비보전 협업 |
| 검사 데이터 이상 탐지 | QC |
| 부적합 보고서 초안 | QC·QA |
| 위생점검 분석 | QC·QA |
| 법규 개정 영향도 분석 | QC·QA |
| 클레임 분류·회신 초안 | QA — QC·고객상담 협업 |
| 협력업체 통보서 초안 | QA — QC·구매 협업 |

직무마다 도구 개수를 합산하면 중복된다. 고유 기능은 여전히 8종이다. 법규 도구는 제공 조문을 분석하며 최신 법규를 자동 수집하지 않는다. 시나리오는 안내일 뿐 업무 진행 상태·승인·종결 기록을 저장하지 않는다.

## 구현과 호환성

- 기존 `#production`은 생산기술로 유지하고 생산관리에 `#planning`을 추가했다.
- 직무 아래 근무지 정보는 제거했다. 가상 데이터 안의 공장 식별자는 분석용이므로 유지했다.
- 기존 계산·API·샘플 응답은 바꾸지 않았다. 공통 도구는 같은 구현을 재사용한다.
- 화면의 출처 링크, 루트 README, 앱 README와 이 문서를 연결한다.
- 이전 분석 문서 01·02는 초기 기획 이력으로 보존하며 현재 직무 기준으로 사용하지 않는다.

## 검증 항목

- 네 직무 전환·전체 보기·기존 해시·새 해시
- 모든 영역 선택, 두 업무 목록의 분리, 직무별 두 상황 선택
- 모든 업무·절차의 도구 연결이 해당 직무 내 도구를 가리키는지
- QC에서 검사 결과를 부적합 초안으로 전달하는 기존 기능
- 공유 도구의 샘플 실행 및 탭 이동
- 데스크톱·모바일 화면, 출처·도구 안내, 근무지 미표시
- 타입 검사·자동 테스트·정적 빌드, 공개 페이지 갱신 확인
